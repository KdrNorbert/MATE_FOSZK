# 🎓 MATE - Programtervező Informatikus (FOSZK) Tananyagok

Üdvözöllek a tárolóban! Ez a repozitórium a **Magyar Agrár- és Élettudományi Egyetem (MATE)** Programtervező informatikus FOSZK képzése során szerzett tananyagaimat, gyakorló feladataimat és beadandó projektjeimet tartalmazza.

---

## 📂 Mappa struktúra

A tároló félévek és tantárgyak szerint van felépítve:

```text
.
├── 1_felev/
│   ├── [Tantárgy_Neve]/
│   │   ├── eloadasok/       # Előadás diák és jegyzetek
│   │   ├── gyakorlat/       # Órai gyakorló feladatok és forráskódok
│   │   └── beadandok/       # Egyéni és csoportos feladatok
├── 2_felev/
├── 3_felev/
├── 4_felev/
└── README.md

```

## 🛠️ Használt technológiák és eszközök

* **Programozási nyelvek:** C#
* **Fejlesztőkörnyezetek:** Visual Studio, Visual Studio Code
* **Verziókövetés & Egyéb:** Git, GitHub, SQL

## 📌 Megjegyzések

* **Tananyagok:** Az órai diák és a megosztott segédanyagok a MATE oktatóinak tulajdonát képezik, kizárólag tanulási célból szerepelnek a tárolóban.
* **Akadémiai tisztaság:** A feltöltött beadandók és gyakorló megoldások saját munka dokumentációiként szolgálnak.
